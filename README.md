# 📊  PROJET D'ANALYSE DE DONNEES COMPLETE AVEC EXCEL

Ceci est un cours Excel complet d'une durée de 11h sur [Youtube](https://www.youtube.com/watch?v=pCJ15nGFgVg&t=35507s) avec Luke Barousse. Elle couvre l'ensemble des connaissances et outils Excel pour l'analyse de données.
[![Excel for Data Analytics](0_Resources/Images/Excel_Data_Analytics_v2.png)](https://youtu.be/pCJ15nGFgVg)

Les connaissances appliquées lors de ce cours sont : 
- Les fonctions et formules Excel
- Les graphiques
- les tableaux dynamiques croisés
- Power Query
- Power Pivot
- DAX : Data Analysis EXpressions

Les connaissances sur ce cours sont aussi pratiques avec 2 projets.
